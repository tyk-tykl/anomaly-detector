# Детектор аномалий

Веб-приложение на Streamlit для поиска необычных транзакций в данных по кредитным картам. Позволяет запустить один из четырёх алгоритмов, посмотреть найденные аномалии и сравнить алгоритмы между собой по качеству и времени работы.

## Возможности

- Загрузка собственного CSV-файла с транзакциями
- Четыре алгоритма: **Z-score**, **Isolation Forest**, **LOF** (Local Outlier Factor), **One-Class SVM**
- Метрики качества (Precision, Recall, F1-score), если в файле есть столбец `Class`
- Режим «Сравнить все алгоритмы»: оценка на отложенной выборке и время работы
- Графики результатов и скачивание найденных аномалий в CSV

## Данные

Проект рассчитан на датасет [Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud) с Kaggle: около 284 тысяч транзакций, из них мошеннических около 0,17%. Столбец `Class` содержит 1 для мошеннических транзакций и 0 для обычных.

Сам датасет в репозиторий не включён из-за размера (около 150 МБ). Скачайте `creditcard.csv` и положите его в `data/raw/`.

В приложении можно загрузить любой CSV с числовыми столбцами. Столбец `Class` необязателен: без него приложение просто найдёт аномалии, но не сможет посчитать метрики.

## Установка

Нужен Python 3.10 или новее.

```bash
git clone <ссылка-на-репозиторий>
cd anomaly-detector

python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux / macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

## Запуск

Из корня проекта:

```bash
streamlit run app.py
```

Приложение откроется в браузере (обычно по адресу http://localhost:8501). Выберите алгоритм в боковой панели, загрузите CSV и нажмите «Запустить анализ» или «Сравнить все алгоритмы».

## Как это работает

1. **Подготовка.** Остаются только числовые столбцы (без `Class`). Пропуски заполняются медианой, затем признаки масштабируются `StandardScaler`.
2. **Поиск аномалий.** Выбранный алгоритм помечает каждую транзакцию как обычную (0) или аномальную (1).
3. **Оценка качества.** Для честного сравнения данные делятся на обучающую (80%) и проверочную (20%) части. Модель учится на первой, а метрики считаются на второй, то есть на данных, которых она раньше не видела.

Особенности алгоритмов в этом проекте:

- **Z-score:** транзакция считается аномальной, если хотя бы один признак отклоняется от среднего больше чем на 3 стандартных отклонения. При 30 признаках это даёт много срабатываний и низкую точность.
- **LOF и One-Class SVM** обучаются на случайной подвыборке до 5000 записей, иначе они слишком медленные на больших файлах.
- **Метрики после обычного анализа** считаются на всём файле, который модель уже видела при обучении, поэтому они немного оптимистичнее, чем в режиме сравнения.

## Структура проекта

```
anomaly-detector/
├── app.py                 # интерфейс на Streamlit
├── requirements.txt
├── data/
│   ├── raw/               # исходный creditcard.csv (не в репозитории)
│   └── processed/         # очищенные данные (не в репозитории)
├── src/
│   ├── preprocessing.py   # очистка и масштабирование признаков
│   ├── evaluate.py        # поиск аномалий, метрики, сравнение алгоритмов
│   └── models/
│       └── __init__.py    # описание алгоритмов и функция fit_predict
├── scripts/               # вспомогательные скрипты (осмотр и визуализация данных)
└── results/               # графики и результаты экспериментов
```

## Используемые технологии

Python, Streamlit, pandas, NumPy, scikit-learn, Altair (графики в приложении), Matplotlib (графики в скриптах).
